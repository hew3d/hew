Hew — Linux packages

These are auto-built from every Hew release. Looking for macOS, Windows, an AppImage, or a .deb/.rpm instead? See the main downloads page.

Arch Linux (x86_64 only)

A signed pacman repository, added once:

curl -O https://hew3d.github.io/hew-packages/pacman/hew-packaging.gpg
sudo pacman-key --add hew-packaging.gpg
sudo pacman-key --lsign-key "$(gpg --with-colons --show-keys hew-packaging.gpg | awk -F: '/^fpr/{print $10; exit}')"

sudo tee -a /etc/pacman.conf <<'EOF'
[hew]
SigLevel = Required
Server = https://hew3d.github.io/hew-packages/pacman/$arch
EOF

sudo pacman -Sy hew-bin

Gentoo

An overlay, added once:

eselect repository add hew3d git https://github.com/hew3d/gentoo-overlay.git
emerge --sync hew3d
echo 'media-gfx/hew-bin ~amd64 ~arm64' | sudo tee /etc/portage/package.accept_keywords/hew-bin
sudo emerge media-gfx/hew-bin

Flatpak

Install for your user, with Flathub providing the GNOME runtime:

flatpak remote-add --user --if-not-exists flathub https://dl.flathub.org/repo/flathub.flatpakrepo
flatpak remote-add --user --if-not-exists hew https://hew3d.github.io/hew-packages/flatpak/com.hew3d.Hew.flatpakrepo
flatpak install --user hew com.hew3d.Hew

Or download the single-file bundle from the latest release and install it with flatpak install --user ./hew.flatpak — it sets up the same remote automatically, so flatpak update --user keeps it current afterward.
