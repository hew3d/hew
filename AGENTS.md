# Hew — Agent Instructions

The instructions for coding agents working in this repository are in
[CLAUDE.md](CLAUDE.md). They apply to every agent, whatever its name: read
that file first and follow it as if it were this one.

In short: read `docs/dev/DEVELOPMENT.md` (section 3, "The rules") before
changing anything; run `scripts/verify.sh` before every commit; never
weaken or delete a failing test; sign off every commit (`git commit -s`);
and put no AI or tool attribution anywhere in a commit message.
